# Fitness-Coaching-Sales-Dashboard
Power BI sales performance dashboard for a fitness coaching platform with automated data generation and documentation

# Step-by-Step Guide: How to Review This Project 

# Step 1: Review Data Generation Code 

**Location: 1. Source Files** 

*Action*: Open the Python Jupyter Notebook (Python Code pdf) and open the link to review how the 20,000 synthetic fitness sales transactions were generated. 

 

# Step 2: Review the Cleaned Dataset & Access the Power BI Dashboard 

**Location: 1. Source Files** 

*Action:*  

Open fitness_coaching_sales_data.xlsx in Excel to inspect the raw transactional records. 

Open Power Bi Dashboard Link Word file in this folder to find the direct Power BI report link, to interact live with the dashboard, view KPI cards, and test the slicers. 

# Step 3: Read the Project Documentation 

**Location: 2. Project Documentation**

*Action:* Open Project Documentation.pdf to read the complete end-to-end report covering business use cases, problem statements, scope boundaries, KPI definitions, and methodology. 

# Step 4: Verify Test & Validation Evidence 

**Location: 3. Validation Evidence**

*Action:* Review the stored validation screenshots to confirm data schema health, Power Query checks, and dashboard. 

# Step 5: Explore the Final Presentation 

**Location: 5. Presentation**

*Action:* Open Fitness & Wellness Coaching Dashboard.pdf to view the executive slide deck demonstrating dashboard visuals, interactive cross-filtering, and actionable business insights.
